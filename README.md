# Neiroot Ecosystem

Мультитенантная SaaS-платформа для бизнесов.

[Философия и концепция продукта](docs/philosophy/index.md) — для чего человеку личная экосистема и как в ней устроено участие в предприятиях.

**Состояние первого этапа:** реализованы web, Go BFF/ядро, вход через Keycloak, экосистемы, сотрудники, предприятия с деревом отделов, назначения и организации. Поддерживаются архив/восстановление и связи организаций с предприятиями. Остальные разделы обозначены «В разработке». Результаты функциональных проверок и оставшаяся приёмка — [test-report.md](docs/test-report.md).

## Разделение общих и персональных файлов

В Git хранятся исходники, переносимые контейнерные конфигурации и шаблоны без секретов. Скрипты конкретной ОС, команды для машины и её журналы ведутся только в игнорируемой рабочей области. Правила подготовки новой машины — [AGENTS.md](AGENTS.md); Windows-автоматизация не входит в состав клона. Переносимость контейнерных конфигураций не означает, что автоматизация для macOS уже реализована или проверена.

## С чего начать

Агент начинает с [AGENTS.md](AGENTS.md) и выбирает профильные документы по типу задачи. Текущая сводка находится в [PROJECT_MEMORY.md](PROJECT_MEMORY.md#текущее-состояние), при продолжении незавершённой реализации полезен [документ передачи](docs/implementation-handoff.md). Пользовательские ответы и незакрытые решения находятся в [open-questions.md](docs/open-questions.md).

[Оглавление документации разработки](docs/index.md) — маршруты по задачам, действующие правила и источники.
