# Первоисточники Neiroot Ecosystem

В `RAW/` хранятся оригиналы материалов, принятых для разработки. Эта страница описывает приём и связывает каждую редакцию с её темой в [вики](../docs/index.md).

## Как принять материал

1. Определи дату получения, происхождение (кто передал материал или откуда он получен) и тему. Найди по этим признакам прежние редакции в таблице ниже. Если происхождение неизвестно, так и укажи.
2. Сохрани оригинальный файл под его именем в каталоге `ГГГГ-ММ-ДД-тема/`. Сопутствующие материалы одного поступления можно хранить вместе. Сохраняй принятые оригиналы и пути к ним. Если материал из того же источника поступил повторно с тем же содержимым, используй существующую запись. При сомнении сравни SHA-256.
3. Изменённый оригинал прими отдельной редакцией. При совпадении даты и темы используй следующий свободный суффикс каталога (`-v2`, `-v3`). Добавь строку с датой, происхождением, ссылками на новые файлы, предыдущую редакцию и страницу темы. Прежняя редакция остаётся доступной по прежнему пути.
4. Обнови профильную страницу по [правилам ведения вики](../docs/workflows/knowledge-maintenance.md). Рядом с выводом поставь ссылку на конкретный файл нужной редакции. При расхождении версий укажи, к какой из них относится каждый вывод. Проверь ссылки в обе стороны и сохранность оригиналов.
