# Агенты платформы

Статус — целевая архитектура. Первый этап включает web, BFF и Core. AI-агенту предусмотрен доступ через бизнес-API в контексте экосистемы и разрешённых действий. Конкретные инструменты, память и обработку сбоев фиксируют при принятии решения о соответствующем агенте.

Для каждого документированного агента создайте каталог с обзором его задач, входов и результатов, инструментов, разрешений, памяти, вызовов сервисов и реакции на сбои. Свяжите обзор с контрактами, сценариями, решениями и, после реализации, кодом и проверками.
