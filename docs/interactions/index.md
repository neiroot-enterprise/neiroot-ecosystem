# Взаимодействия

[Получение списка сотрудников](list-employees.md) — действующий HTTP-сценарий web → BFF → Core. Для нового сквозного сценария укажите участников, владельца данных и контракта, известных потребителей, последовательность, права, ошибки и проверки. Для событий также укажите издателя и подписчиков. Реализованные связи сверяйте с кодом, планируемые — с решением и статусом в [архитектуре](../architecture.md).
