# Передача текущей реализации

Работа начата по утверждённому плану пользователя от 2 октября 2026 года. Читать [AGENTS.md](../AGENTS.md), [Agent.md](../Agent.md), [mvp.md](mvp.md), [test-report.md](test-report.md), затем профильные документы.

Существующий проект: apps/web (React/TS), services/bff и services/core (Go/chi), общий технический internal, infra и scripts. Четыре модуля ядра; company владеет карточками сотрудников, settings — tenant/членствами/ролями/приглашениями. Модульные SQL-адаптеры не используют чужие таблицы. Домен независим. Контракт — docs/api/openapi.json.

Не потерять существующие материалы, оригинал логотипа, историю решений и локальные секреты. Основной запуск — scripts/start-local.ps1, адрес https://localhost:8443. После ручной перезагрузки Windows Docker Engine работает; проект собран и оставлен запущенным. Нативная среда использовалась только для реальной интеграционной проверки, содержит синтетические данные и остановлена.

Docker build/health и повторные миграции проверены. Осталось выполнить полный повтор бизнес-сценариев, сохранение volumes после остановки/старта и чистую установку в отдельном тестовом Compose project без удаления основной .env и пользовательских данных. Тесты с созданием синтетических аккаунтов не запускать в основном пользовательском пространстве. Обновить test-report, Agent и mvp по результату; не объявлять всю контейнерную приёмку выполненной по одному успешному запуску.

Писем, email verification/recovery, должностных прав, финансовых CRUD, удаления/редактирования сотрудников, брокера и остальных микросервисов пока нет. Вопросы будущих этапов находятся в open-questions.
