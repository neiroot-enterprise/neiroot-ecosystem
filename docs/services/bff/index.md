# BFF

Работающий Go-сервис обслуживает браузерную сессию, взаимодействует с Keycloak и проксирует прикладные HTTP-запросы в Core. Данные сессии и токены принадлежат BFF. Для операций записи применяются проверки происхождения запроса и CSRF. Бизнес-правила и проверку доступа к данным выполняет сервис-владелец.
