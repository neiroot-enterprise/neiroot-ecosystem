# Настройки

- **Поля:** настройка полей; типы, применимость и правила пользователь пока не определил.
- **Права доступа:** экран пока «В разработке»; серверные экосистемы, членства, приглашения и owner/admin/user принадлежат этому модулю. Детальные права по должностям отложены.

Кнопки создания, экраны списков и вложенные вкладки сохранены в этой документации. На архитектурной схеме показаны модули и основные разделы, без детализации экранов и диаграмм последовательностей.

Реализованы серверные экосистемы, членство, роли и приглашения.
