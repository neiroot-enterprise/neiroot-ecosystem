# Core

Работающий Go-сервис содержит модули предметной области и хранит их данные в PostgreSQL. HTTP-вызовы браузера проходят через BFF. Core проверяет идентичность и доступ к экосистеме. Модули взаимодействуют через явные порты, владеют своими таблицами и развёртываются вместе.

- [Моя экосистема](modules/company/index.md) — сотрудники, справочники и назначения.
- [Настройки](modules/settings/index.md) — экосистемы, членства, роли, приглашения и личный порядок меню.
- [Деньги](modules/money/index.md) и [Продажи](modules/sales/index.md) — зарезервированные границы.
