## 2026-11-20 · Документация разработки
По утверждённому командой плану введены [оглавление](../index.md) и [порядок обслуживания](../workflows/knowledge-maintenance.md). Исходные сводки перенесены по ссылкам выше. История прогонов доступна из [отчёта о приёмке](../test-report.md). Следующие датированные записи добавляются в конец.

## 2026-11-20 · Приёмка навигации

В новой сессии Codex от оглавления найдены источник цветов и реализация Button, владелец данных сотрудников, маршрут web → BFF → Core → PostgreSQL, статус будущих агентов и оставшаяся приёмка приложения. Пройдены оба примера слияния правил кнопки. По результату сверки с записью MVP от 17 ноября уточнён статус оформления каталогов в [плане реализации](../implementation-plan.md). Проверка охватывала документацию и чтение кода.

## 2026-11-20 · Оформление регистрации

По заданию пользователя оба шага Keycloak приведены к актуальному дизайну входа: общая шапка, Onest, компактная карточка, поля и действия, две темы. Состав и обязательность полей сохранены. Переиспользованы CSS и переключатели входа, добавлен существующий ресурс надписи для тёмного фона. [Правила оформления](../design/login.md#регистрация) · [Результаты: 8/8 браузерных проверок, typecheck и сборка](../test-reports/2026-11-access.md#регистрация-в-актуальном-дизайне--20-ноября-2026).

## 2026-11-20 · Состояния авторизации

По следующему заданию пользователя обновлены состояния входа и регистрации по актуальным Input/Button. Пользователь явно выбрал текущий Input для ошибок; старые значения найдены в реализации и тестах, наличие отдельного утверждённого макета не подтверждено.
