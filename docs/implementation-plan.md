# Реализация первого этапа

Утверждённый источник — пользовательский план от 2 октября 2026 года. Выбор этапа больше не отложен. Границы — [mvp.md](mvp.md).

1. Сохранить материалы и закрепить версии; персональную подготовку вести по AGENTS.md.
2. Согласованные сценарии отразить в модели доступа и OpenAPI; генерировать типы клиента/сервера.
3. Разделить BFF и ядро, модули company/settings, PostgreSQL роли и RLS; добавить миграции.
4. Реализовать серверный OAuth и тему Keycloak, пространство владельца и переключение.
5. Реализовать сотрудников, оба способа подключения и роли; остальные экраны оставить «В разработке».
6. Проверить реальные PostgreSQL/Keycloak, права/tenant/повторы/сбои, UI и сборки.
7. Завершить контейнерную приёмку, обновить функциональный отчёт.

Новые требования к будущим CRUD не расширяют этот этап без отдельного решения. Текущая степень выполнения и ограничения — [test-report.md](test-report.md), [PROJECT_MEMORY.md](../PROJECT_MEMORY.md).
